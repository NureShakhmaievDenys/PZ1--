- Input Pack, Decision Log, Screen Map і Screen Contracts;
- Figma Brief, Figma screenshots і клікабельний prototype;

- AI Interaction Logs учасників;
- матеріали розширення V2: пошук, фільтри, теги, строки, вкладення та підзадачі;
- фінальний звіт у форматах DOCX та PDF.

Примітка: Figma-макет є UI-прототипом. Реальна автентифікація, backend, server persistence і file storage не реалізовані.
