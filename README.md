# Mini Issue Tracker UX UI

Практична робота № 1-2 з дисципліни «Штучний інтелект у програмній інженерії».

## Проєкт

Mini Issue Tracker — low-fidelity UX/UI-прототип вебсистеми для створення, перегляду та супроводження задач однієї команди.

Release MVP охоплює US-01–US-08: списки All Issues та Important Issues, створення задачі, перегляд деталей, коментарі, призначення виконавця, зміну пріоритету й статусу.

## Посилання

- Figma prototype: https://www.figma.com/design/a8oUbf6v4MtBhqgk8yJfbT/Untitled?node-id=0-1&p=f&t=YzhRyMTQxb0k2GH6-0

Перед здаванням перевірте, що Figma-файл перейменовано на `Mini Issue Tracker`, а викладач має доступ на перегляд за посиланням.

## Структура репозиторію

- `00_Source/` — вихідна специфікація.
- `01_...` – `08_...` — результати аналізу, проєктування, review та тестування.
- `09_AI_Interaction_Log.md` — журнал використання AI-інструментів.
- `10_...` – `12_...` — corrected screen set, Figma brief and manual rebuild checklist aligned with the methodological guide.
- `13_...` – `16_...` — optional enhanced V2 scope: search and filters, tags, due dates, attachments and subtasks.
- `screenshots/` — докази станів Figma-макету.
- `report/` — фінальний звіт у DOCX; PDF додається після експорту з Word.
- `submission/readme.txt` — короткий файл для завантаження в DL.
- `video/` — посилання або файл відеозапису для заочного захисту, якщо його вимагає викладач.

## Межі прототипу

Прототип використовує демонстраційні дані. Реальна автентифікація, backend, серверне збереження, вкладення, сповіщення, пошук, фільтрація та AI-функції не реалізовані в межах MVP.
